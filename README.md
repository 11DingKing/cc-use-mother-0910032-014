# 活动评价异常申诉

本项目维护活动评价异常申诉的领域约定、角色边界与样例数据，供后端服务、接口和自动化验证统一使用。当前契约覆盖活动统筹员、讲解员、学校联系人、场馆管理员，并明确评价来源可信度、异常复核案件、发布评价集冻结、匿名信息裁剪等关键约束。

## 目录

- `domain/contract.json`：领域角色、状态、约束和样例。
- `src/domain_contract/`：契约读取与确定性校验。
- `src/review_appeal/`：异常申诉后端（评价记录、异常检测、复核案件、发布集与等级、讲解员接口）。
- `tools/check_contract.py`：命令行摘要检查。
- `tests/`：契约完整性与后端行为回归测试。

## 后端行为要点（`src/review_appeal/`）

- **评价记录**：每条评价保存来源渠道、身份验证级别、评分版本与提交指纹，创建后不可修改。
- **异常复核案件**：异常规则（重复提交、异常账号）命中只产生信号并建复核案件，绝不自动改分。
- **处置保留原值**：合并重复、部分采纳、申诉撤回、决定重开都只追加案件事件；部分采纳的排除仅作用于下一次发布。
- **发布评价集冻结**：等级计算绑定发布后冻结的评价集快照，新评价与新决定不影响已发布版本，历史版本可重算且结果不变。
- **匿名信息裁剪**：讲解员接口展示影响解释（当前等级 vs 排除后估算等级），评价者以稳定化名出现，账号、联系方式、提交指纹不出接口。

## 验证

测试命令：`python3 -m unittest discover -s tests -v`

编译命令：`python3 -m compileall -q src tools tests`

命令行检查：`python3 tools/check_contract.py domain/contract.json`
